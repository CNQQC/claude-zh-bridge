# 桌面安装、更新与恢复

当前支持 Apple Silicon、macOS 14+ 和 Claude Desktop 3.1623.0。版本限制来自实际验证结果，不代表 Anthropic 官方支持。本项目适配原应用的 Chat 与左侧 Code，不适配终端 CLI。

## 安装前

- 记录并保留未发送的草稿，等待回复、Code 任务和后台命令结束。
- 完全退出 Claude。工具发现应用仍在运行时会停止。
- 在「接口」中填写自己的 Key，保存并按需「测试连接」。连接测试只检查模型列表，不提交翻译文本。

## 工具怎样安装

1. 验证应用身份、受支持版本与 ASAR 资源哈希。
2. 保存完整原版备份，或校验已经托管的原版备份。
3. 在副本中生成资源补丁，保留完整性校验。
4. 按组件顺序本地签名，严格验证候选应用。
5. 写入安装事务和回滚副本，再原子替换已校验的文件。
6. 保存安装记录，后续设置修改不再改动应用或重新签名。

桌面补丁会替换官方签名，并仅对所选应用添加动态库签名匹配例外。不会关闭 SIP、Gatekeeper、沙箱、资源完整性检查或官方更新。macOS 可能再次要求钥匙串或应用身份确认，请在系统窗口中自行处理。

## 更新已有补丁

由中文桥安装过的应用，选择同一个应用后使用「更新补丁」。来自旧版本地脚本的安装需要先导入属于你自己的完整原版备份清单；工具会校验并复制备份，不会把修改过的应用当作原版。

公开仓库不提供作者的清单或 Claude 原版应用，也不会猜测一个备份是否属于你。若应用已自动更新，或安装文件/备份哈希发生变化，工具会拒绝覆盖。

## 恢复

完全退出 Claude，选择「恢复原版」。原始文件与签名恢复，Claude 的账号数据、聊天记录、个人设置和翻译缓存保留。

若安装曾意外中断，下次运行会显示中断状态。选择「恢复中断操作」会先核对事务、回滚副本与当前文件，只有状态匹配才继续。不要在恢复过程中手动移动原版备份或修改安装清单。

## 已知边界

- Claude 自动更新后可能需要重新适配。不要绕过版本或哈希检查。
- 修改应用资源的方式不是官方插件入口，不能保证未来版本兼容。
- 原生复制、工具批准和代码操作保持原路径；中文显示层不是 Claude 服务器内容的改写。
- 未经 Apple 公证的本地签名应用可能触发 macOS 提示。本项目不提供关闭系统安全保护的脚本。
