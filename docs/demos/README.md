# 实际演示素材

`../media/claude-live.gif` 和静态 PNG 来自真实 Claude Desktop，而不是网页重绘或模拟聊天截图。

- 使用专用公开演示对话；内容只讨论输入、发送、阅读的翻译流程。
- 录制英文回复生成、自动中文显示，以及刷新后的中文恢复。
- 隐藏账户与历史侧栏；输出画面裁去应用外围和无关区域。
- 只做裁切、缩放、外部字幕与等待时间压缩，不替换或合成消息/界面。
- 原始完整画面不在仓库中。公开素材经过逐帧查看与本地文字识别检查，不包含账户姓名、会话 ID、Key、邮箱、真实历史标题或本机路径。
- 未将其他正在运行的 Code 会话或任务录入演示。

可用 `scripts/render_demo.py` 处理你自己录制的 PNG 帧与 `frames.json`。脚本中的裁切区域专门适用于该录制分辨率，换设备时必须重新检查。Pillow 仅用于媒体编辑，不是扩展或桌面工具的运行依赖。

本目录不保存原始录屏、设备账户或接口响应。演示证明可见的操作过程，性能、请求合并与费用边界请看 [验证范围](../verification.md)。
