# 数据与隐私

中文桥没有自建代理或统计服务。默认翻译服务为 `https://api.deepseek.com`；桌面版也可填写自己的 HTTPS 接口。原始 Claude 会话仍由 Claude 自己处理，本项目不代理 Claude 登录、Cookie 或模型请求。

## 什么会离开设备

支持会话中需要翻译的文字，包括中文输入、英文回复和会话标题，会发给你配置的翻译接口。代码围栏、行内代码、公式和 URL 会尽量跳过。此保护是启发式规则，不是敏感信息识别器；不要依靠它阻止秘密出现在普通正文里。

项目不发送聊天缓存、目录列表或其他会话的完整历史来辅助翻译。只处理当前已渲染并符合范围规则的文本。翻译服务会按自己的规则处理你提交的内容。

## 什么保存在设备上

| 数据 | Chrome | Claude Desktop |
| --- | --- | --- |
| API Key | `chrome.storage.session`，限受信任后台上下文；浏览器重启后重新填写 | `~/Library/Application Support/Claude/czt-desktop/config.json`，0600 |
| 译文、原中文稿、显示快照 | `chrome.storage.local` | 同目录 `cache.json`，0600 |
| 开关 | Chrome 本机存储 | `config.json` |
| 原版备份、安装与恢复记录 | 不适用 | `~/Library/Application Support/Claude 中文桥/` |

Key 不由状态接口返回给会话脚本，不放进请求 URL，也不写入翻译缓存。桌面配置仍是本地明文文件，并非 macOS 钥匙串或加密保险箱。缓存可能包含完整聊天文字，应保护设备和备份。

## 避免重复提交

请求前保存处理中标记；成功后先保存结果，再显示译文。处理中断或结果无法确认时不会自动再次计费。手动「重试」只移除失败/中断标记，成功缓存保留。

重复内容共享片段结果和进行中的请求。改变桌面接口或模型会更换缓存命名空间，旧结果继续保留。Chrome 和 Desktop 的缓存各自独立。

## 清除与卸载

Chrome：先导出你需要的内容，再卸载扩展或清除扩展数据。此操作可能删除全部本机译文。

Desktop：先通过中文桥「恢复原版」，再按需要自行删除配置与缓存。恢复应用本身不删除聊天记录、个人设置或翻译缓存。不要在官方更新后手动覆盖旧版应用资源。

## 公开报告

不要上传 Key、Cookie、配置文件、聊天缓存、原版应用、安装清单或带账户信息的截图。演示应使用独立的公开测试对话；本仓库只包含脱敏后的演示素材。
