# 验证范围

本项目区分模拟回归、真实接口验证和实际界面观察，不将其中一种替代成另一种。

## 自动化回归

`npm test` 使用 jsdom、模拟服务和临时存储，覆盖发送拦截、组合输入、失效结果丢弃、会话/非会话范围、工具调用后的追加块、Code 原生控件、标题、持久缓存、重复请求合并和错误处理。

批量用例包括：70 个 Code 段落与一个标题，故意延迟一个块的缓存读取，仍只产生一次模拟模型请求；刷新重建后不再产生付费请求。超长文本保留最小必要分批与返回顺序。

原生测试覆盖文件摘要、路径隔离、配置校验、私有文件权限与中断恢复。完整安装/恢复集成需要一份本地、未经修改的受支持 Claude 副本，不会下载或分发 Claude，也不在默认 CI 中修改系统应用。

## 真实接口验证

在首次公开版本整理前，曾使用与已安装后端逐字节一致的代码，在独立进程与独立测试缓存中发送三条无隐私短句：一次真实 DeepSeek 请求返回三条中文结果；重新创建后端后复用三条缓存，新增网络请求为零。

这证明该后端的真实批量协议与缓存恢复路径；它不是在一个空缓存页面中对所有 DOM 节点进行的端到端计费基准。本文不发布用户的请求编号、个人账户状态或原始缓存。

## 实际界面

演示 GIF 来自真实 Claude Desktop 3.1623.0，使用专门的测试对话。画面展示中文输入、英文回复生成、完成后中文显示，以及刷新后的恢复。录制时运行的是桌面补丁 1.3.0；公开版 1.6.0 保留同一翻译/缓存行为，去除了私人默认配置，并整理了构建与公开设置。

另外实际观察过 Code 正文、标题和表格的中文显示。Code 标题、列表和表格的旧快照恢复格式已增加回归用例。

## 不据此承诺

不承诺所有 Claude 未来版本、全部 DOM 变化、所有语言内容或固定翻译质量。不承诺固定百分比的账单降低。缓存命中、文本大小、模型输出长度与使用方式都会影响请求数量和费用。
